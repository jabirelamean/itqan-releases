# إتقان القرآن — Itqan Al-Quran

منصة لإدارة مراكز تحفيظ القرآن الكريم ومتابعة الحفظ: الورد اليومي بثلاثة مسارات، الحلقات والروايات، الشهادات والتقارير. تعمل بدون إنترنت مع مزامنة سحابية.

A platform for running Quran memorization centers — daily ward tracking in three parallel tracks, circles & riwayat, certificates and reports. Works offline with cloud sync.

**Download & details:** https://jabirlabs.com/work/itqan/

This repository only hosts the Android download file (see **Releases**).
